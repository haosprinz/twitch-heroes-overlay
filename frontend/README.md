# Twitch Heroes — Frontend

Независимое Vue-приложение. Полный план: [../PLAN.md](../PLAN.md).

Запускается отдельно от backend. Общей точки запуска нет.

```bash
npm install
copy .env.example .env
npm run dev
```

| Страница | URL |
|---|---|
| Overlay (OBS) | http://localhost:5173/overlay |
| Админка героев | http://localhost:5173/admin |
| Чаттеры | http://localhost:5173/chatters |
